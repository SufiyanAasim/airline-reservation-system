# Test Suite & Guidance

Manual verification wizard guidelines for Airline Reservation System:

1. **Authentication Verification**: Verify login and signup with password eye toggle button (👁 / 🙈).
2. **Clearance Phase**: Select flight routes (e.g. KHI -> ISB) and validate passenger registration.
3. **Taxi Phase**: Verify interactive seat selection grid and cabin class multipliers.
4. **Ascent Phase**: Test baggage weight calculator and excess weight fee logic.
5. **Cruising Phase**: Inspect dynamic GDI+ load factor bar chart rendering.
6. **Report Generation Phase**: Build and export TXT / CSV audit reports to disk.
7. **Touchdown Phase**: Verify printable boarding pass card and flat-file logging.
8. **Mayday Phase**: Test emergency Squawk 7700 protocol and contributor credits.
