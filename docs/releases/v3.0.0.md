# Airline Reservation System — v3.0.0

> *Codename: Ascent*

---

## 📖 Overview

Ascent is the third version release, focusing on checked baggage weight check-in, excess weight fee calculation, and in-flight amenity add-ons.

---

## 🎯 Objectives

* Implement baggage weight check-in with cabin allowance limits (`BaggageAscentForm`).
* Calculate excess baggage fees at $12.50 / kg.
* Add in-flight meal selection and optional amenity add-ons (Wi-Fi, Executive Lounge, Express Boarding).

---

## ✨ Added

### 🛬 Baggage & In-Flight Service Customization

* `BaggageAscentForm.cs` — baggage allowance calculator enforcing 20kg (Economy), 35kg (Business), and 50kg (First Class) limits.
* Meal preference selector (Gourmet Halal, Vegan, Diabetic, Child, Gluten-Free).
* Optional amenity toggles updating total booking costs in real time.
