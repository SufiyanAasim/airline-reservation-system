# Airline Reservation System — v6.0.0

> *Codename: Mayday*

---

## 📖 Overview

Mayday is the current release of the Airline Reservation System, introducing an emergency Squawk 7700 flight abort protocol, aircraft health diagnostic alerts, system incident logging, live radar animations, SQLite database persistence, PCM wave audio feedback, executive report exports, and a dedicated project credits section.

Building on the foundation established across previous flight phases, Mayday completes the aviation journey from clearance to emergency handling.

---

## 🎯 Objectives

* Implement emergency Squawk 7700 transponder broadcast simulation (`MaydayForm`).
* Display real-time aircraft health telemetry (hydraulic pressure, cabin oxygen, transponder status, fuel jettison).
* Integrate SQLite database storage (`AirlineSystem.db`) for transaction logging.
* Implement custom 44.1kHz PCM wave audio feedback across all buttons and controls.
* Add live WinForms animations (pulsing radar beacon, live flight telemetry pulse, marquee status ticker).
* Provide Executive Report Generator supporting `.txt` and `.csv` spreadsheet exports.
* Provide project credits section featuring author profile.

---

## ✨ Added

### 🚨 Emergency Mayday Control, SQLite Storage & Team Credits

* `MaydayForm.cs` — interactive emergency Mayday trigger button, fail-safe rerouting overlay, live pulsing radar beacon, fuel jettison progress animation, diagnostic telemetry log stream, and zero-gap full-height grid.
* `DatabaseService.cs` — embedded **SQLite Database (`AirlineSystem.db`)** integration via `Microsoft.Data.Sqlite` for ACID transaction persistence.
* `SoundHelper.cs` — custom 44.1kHz 16-bit PCM WAV audio synthesizer for tactile UI button taps and Mayday sirens.
* `ReportGenerationForm.cs` — Executive Flight Manifest and Revenue Audit Ledger report builder with `.txt` and `.csv` export engine.
* `CreditsForm.cs` — dedicated system credits screen with author profile card, tech stack badges, and interactive GitHub/Email buttons.
* Release packaging automation (`scripts/package-release.ps1` & `scripts/publish-releases.ps1`).
