# Airline Reservation System — v6.0.0

> *Codename: Mayday*

---

## 📖 Overview

Mayday is the current release of the Airline Reservation System, introducing an emergency Squawk 7700 flight abort protocol, aircraft health diagnostic alerts, system incident logging, and a symmetrical project contributor credits section.

Building on the foundation established across previous flight phases, Mayday completes the aviation journey from clearance to emergency handling.

---

## 🎯 Objectives

* Implement emergency Squawk 7700 transponder broadcast simulation (`MaydayCreditsForm`).
* Display real-time aircraft health telemetry (hydraulic pressure, cabin oxygen, transponder status).
* Provide symmetrical project contributor credits cards featuring developer roles and GitHub profiles.
