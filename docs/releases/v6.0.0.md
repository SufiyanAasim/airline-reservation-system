# Release v6.0.0 — Mayday Emergency Protocol & SQLite Engine

Release **v6.0.0** introduces SQLite database integration, live radar & telemetry animations, PCM audio synthesis, executive report exporting, and Mayday emergency control deck optimizations.

## 🚀 What's New in v6.0.0

- **SQLite Database (`AirlineSystem.db`)**: Full persistence layer storing passenger manifests, PNR codes, fare structures, and flight statuses.
- **Mayday Emergency Control Deck**:
  - Live Pulsing Radar Beacon (green normal / red emergency).
  - Smooth Animated Fuel Jettison progress gauge.
  - Full-height zero-gap control grid with Cockpit Telemetry Log card.
- **Audio Feedback**: Custom 44.1kHz PCM wave synthesizer attached to all buttons across the application.
- **Executive Report Generator**: Export flight manifests and revenue audit ledgers as `.txt` and `.csv` spreadsheets.
- **Clean OS Window Titles**: Standardized top window title bar text to `Airline Reservation System`.
