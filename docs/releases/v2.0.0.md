# Airline Reservation System — v2.0.0

> *Codename: Taxi*

---

## 📖 Overview

Taxi is the second version milestone of the Airline Reservation System, introducing an interactive 2-2 aircraft seating grid and cabin class tier pricing.

---

## 🎯 Objectives

* Build an interactive visual aircraft cabin seat selector (`SeatTaxiForm`).
* Implement cabin class multiplier pricing (Economy 1.0x, Business 1.85x, First Class 3.20x).
* Provide real-time subtotal fare previews during seat selection.

---

## ✨ Added

### 🛞 Interactive Seating Grid & Cabin Pricing

* `SeatTaxiForm.cs` — interactive seating matrix with distinct color indicators for selected (Sky Blue), available (Slate), and occupied (Crimson) seats.
* Radio buttons for Economy Class, Business Class, and First Class tiers.
* Dynamic fare preview calculations.

---

## 🏛️ Architecture Decisions

**State-driven seat controls.** Seat buttons update their appearance and tag metadata dynamically, maintaining selected seat references across navigation screens.
