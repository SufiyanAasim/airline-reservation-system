# Airline Reservation System — v1.0.0

> *Codename: Clearance*

---

## 📖 Overview

Clearance is the first release milestone of the Airline Reservation System, establishing the application's WinForms desktop architecture, user authentication portal, and initial flight departure clearance engine.

This release focuses on establishing the project's form-per-screen architecture, implementing passenger identity registration, and validating the initial wizard navigation flow — before introducing seating grids, GDI+ charts, or emergency fail-safe modes.

The application was designed around a clear separation between WinForms presentation forms, flight route lookup services, and local travel history storage.

---

## 🎯 Objectives

* Establish a clean form-per-screen C# WinForms project structure targeting .NET 8.0.
* Build user authentication (`LoginForm` and `SignupForm`) with interactive **Eye Toggle Buttons (👁 / 🙈)** to show/hide passwords.
* Implement flight departure search and clearance validation (`WelcomeClearanceForm`).
* Provide a solid architectural foundation for subsequent seating, baggage, and analytics milestones.

## 🏛️ Architecture Decisions

**Form-per-screen design.** Each phase of the flight journey is represented by a dedicated WinForms `Form` with a clean separation between layout styling and event-handling code.

**Local-first offline design.** All authentication sessions and route lookup operations run locally without requiring remote server infrastructure or cloud databases.
